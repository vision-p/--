# 小组借物登记

这是一个由小组负责人在浏览器中使用的借物登记网页，可以查看共用物品是否可借、谁借走了物品、什么时候应还，以及按时间显示的借还记录。

## 运行

用 VS Code 打开项目文件夹，使用 Live Server 运行 `index.html`，然后在浏览器打开页面。

## 演示

1. 在「物品名称」输入“雨伞”，点击「新增物品」。
2. 点击雨伞旁的「借出」，输入借用人的名字。可以填写应还日期，留空则只登记借用人。
3. 填写昨天的日期可模拟补录一笔逾期借用。确认物品标为「已逾期」，并查看顶部的数量统计。
4. 刷新页面，确认物品、借用人、应还日期和借出记录仍然存在。
5. 点击「归还」，确认雨伞恢复为「可借」，再刷新页面，查看两条借还记录。
6. 如果雨伞已不再供小组借用，点击「删除」并确认。顶部统计会更新，之前的借还记录仍可查阅。

## 数据保存

项目使用 HTML、CSS 和原生 JavaScript，将物品状态、当前借用人、应还日期和操作记录一起保存在当前浏览器的 `localStorage` 中。「最近记录」按最新操作在前的顺序显示。
