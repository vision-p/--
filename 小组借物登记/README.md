# 小组借物登记

这是一个由小组负责人在浏览器中使用的借物登记网页，可以查看共用物品是否可借、谁借走了物品，以及本次打开页面后的借还记录。

## 运行

用 VS Code 打开项目文件夹，使用 Live Server 运行 `index.html`，然后在浏览器打开页面。

## 演示

1. 在「物品名称」输入“雨伞”，点击「新增物品」。
2. 点击雨伞旁的「借出」，输入借用人的名字。
3. 刷新页面，确认物品和借用人仍然存在。
4. 点击「归还」，确认雨伞恢复为「可借」，并查看「最近记录」。

## 数据保存

项目使用 HTML 和原生 JavaScript。物品和当前借用人保存在当前浏览器的 `localStorage` 中。当前版本的最近记录会在刷新后清空。
